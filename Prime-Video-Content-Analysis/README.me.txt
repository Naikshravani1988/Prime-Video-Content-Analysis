# Amazon Prime Video Content Analysis 📊

## Project Overview
This project focuses on analyzing Amazon Prime Video content using Microsoft Power BI. The dashboard provides insights into movies and TV shows available on the platform through interactive visualizations and slicers.

## Objectives
- Analyze the distribution of Movies and TV Shows.
- Understand content ratings and genres.
- Identify the countries with the highest content availability.
- Explore content released over different years.
- Present key insights through an interactive dashboard.

## Tools & Technologies
- Microsoft Power BI
- Power Query
- Data Visualization
- CSV Dataset

## Dataset
The project uses the Amazon Prime Titles dataset (`amazon_prime_titles.csv`), which contains information such as:
- Show ID
- Title
- Type
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Genre

## Dashboard Features
- **KPI Cards:** Total Titles, Rating Categories, Unique Genres, Total Directors, First Release Year, and Latest Release Year.
- **Content by Rating:** Shows the distribution of content across rating categories.
- **Top Genres:** Displays the most common genres.
- **Content by Country:** Shows the geographical distribution of titles.
- **Movies vs TV Shows:** Compares the two content types.
- **Titles by Release Year:** Displays content trends over time.
- **Interactive Slicers:** Filter the dashboard by Release Year and Rating.

## Project Files
- `Prime_Video_Dashboard.pbix` – Power BI dashboard file.
- `Dataset/amazon_prime_titles.csv` – Dataset used for analysis.
- `ScreenShot/Prime_Video_Dashboard.png` – Dashboard screenshot.

## How to Use
1. Download or clone this repository.
2. Open `Prime_Video_Dashboard.pbix` using Microsoft Power BI Desktop.
3. If prompted, update the dataset file path.
4. Explore the dashboard using the Release Year and Rating slicers.
