# Prime Video Dashboard – Power BI

## Project Overview
This project is an interactive Prime Video dashboard created using Microsoft Power BI to analyze movies and TV shows available on the Prime Video platform.

## Dashboard Features
- Total Titles KPI
- Total Movies and TV Shows
- Total Ratings
- Content distribution by Rating
- Top Genres analysis
- Content by Country
- Movies and TV Shows analysis
- Interactive filters and slicers

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Data Visualization
- Data Analysis

## Key Objectives
- Analyze Prime Video content.
- Understand the distribution of movies and TV shows.
- Explore content based on genres, ratings, and countries.
- Present insights through interactive visualizations.
